# A · Glossary

One-line definitions for terms used in the handbook, with the chapter that covers each in depth. Use it for quick revision: cover the definition and say it out loud.

## A–C

- **A/B test**: randomised experiment comparing variants on live traffic to measure causal impact. (Ch 2, 29)
- **Activation function**: non-linearity applied after a linear layer (ReLU, GELU, SiLU). (Ch 6)
- **AdamW**: Adam optimiser with weight decay decoupled from the gradient update; the default for transformers. (Ch 6, 7)
- **Agent**: an LLM in a loop that chooses actions (tool calls) based on observations until a goal is met. (Ch 21)
- **ALS**: alternating least squares, a matrix-factorisation method for implicit-feedback recommenders. (Ch 25)
- **ANN (approximate nearest neighbour)**: fast vector search trading a little recall for speed (HNSW, IVF, PQ). (Ch 17, 18)
- **Attention**: weighted sum of value vectors, with weights from query-key similarity. (Ch 8, 10)
- **AUC (ROC-AUC)**: probability a random positive is scored above a random negative. (Ch 5)
- **Autograd**: automatic differentiation that records operations and back-propagates gradients. (Ch 7)
- **AWQ / GPTQ**: post-training 4-bit weight quantisation methods for LLMs. (Ch 14)
- **Backpropagation**: computing gradients layer by layer with the chain rule. (Ch 6)
- **Bandit**: sequential decision method balancing exploration and exploitation (ε-greedy, UCB, Thompson sampling). (Ch 2, 25)
- **Batch normalisation / layer normalisation**: normalising activations across the batch / across features of one example. (Ch 6)
- **Beam search**: decoding that keeps the B most probable partial sequences. (Ch 14)
- **Bi-encoder / cross-encoder**: encode query and document separately (fast, indexable) / together (accurate, slow). (Ch 17, 18)
- **Bias–variance trade-off**: error from wrong assumptions vs error from sensitivity to the training sample. (Ch 3)
- **BM25**: classic lexical ranking function using term frequency, inverse document frequency and length normalisation. (Ch 18)
- **BPE (byte-pair encoding)**: subword tokeniser built by repeatedly merging the most frequent adjacent pair. (Ch 9)
- **Bradley–Terry model**: P(a preferred over b) = σ(r_a − r_b); the basis of reward models. (Ch 13)
- **Calibration**: predicted probabilities match observed frequencies. (Ch 5)
- **Canary release**: sending a small share of traffic to a new version with automatic rollback rules. (Ch 29)
- **Chain-of-thought**: prompting or training the model to reason step by step before answering. (Ch 15, 13)
- **Chinchilla scaling**: compute-optimal training uses about 20 tokens per parameter. (Ch 11)
- **Chunking**: splitting documents into retrievable passages for RAG. (Ch 19)
- **CLIP**: image and text encoders trained contrastively into a shared embedding space. (Ch 11)
- **Cold start**: no history for a new user or item. (Ch 25)
- **Concept drift / covariate shift / prior shift**: the input–label relation / the input distribution / the label base rate changes. (Ch 29)
- **Constrained decoding**: masking logits so output follows a grammar or schema. (Ch 14)
- **Context window**: maximum number of tokens a model can attend to at once. (Ch 10, 15)
- **Continuous batching**: adding and removing requests from the running batch at each decode step. (Ch 14)
- **Contrastive loss (InfoNCE)**: pull matching pairs together and push in-batch negatives apart. (Ch 11, 17)
- **CUPED**: variance reduction for experiments using a pre-experiment covariate. (Ch 2)

## D–H

- **Data contract**: agreed schema, semantics, freshness and ownership for a dataset. (Ch 30)
- **Data leakage**: information unavailable at prediction time used in training. (Ch 3, 30)
- **DCG / NDCG**: ranking metric with logarithmic position discount, normalised by the ideal ranking. (Ch 5, 26)
- **Decoder-only model**: transformer with a causal mask trained on next-token prediction (GPT, Llama). (Ch 11)
- **Distillation**: training a small student to imitate a larger teacher. (Ch 13)
- **DPO**: direct preference optimisation, learning from preference pairs without a reward model or RL. (Ch 13)
- **Dropout**: randomly zeroing activations during training to regularise. (Ch 6)
- **Embedding**: dense vector representing an item, word or text so that similar things are close. (Ch 8, 17)
- **Encoder-only model**: bidirectional transformer trained with masked language modelling (BERT). (Ch 11)
- **Exposure bias**: training on true previous tokens but generating from one's own. (Ch 8)
- **F1 score**: harmonic mean of precision and recall. (Ch 5)
- **Faithfulness / groundedness**: generated claims are supported by the provided context. (Ch 22, 23)
- **Feature store**: system serving consistent features offline (training) and online (serving). (Ch 29)
- **Few-shot prompting**: including examples in the prompt. (Ch 15)
- **Fine-tuning**: continuing training of a pre-trained model on task data. (Ch 12, 16)
- **FlashAttention**: exact attention computed in tiles to avoid materialising the full matrix; faster and memory-efficient. (Ch 10)
- **GBDT**: gradient-boosted decision trees (XGBoost, LightGBM, CatBoost). (Ch 4)
- **GQA (grouped-query attention)**: several query heads share one key-value head, shrinking the KV cache. (Ch 10, 14)
- **Gradient clipping**: capping gradient norm to avoid exploding updates. (Ch 6, 7)
- **GRPO**: RL method using group-relative rewards as advantages, without a value model. (Ch 13)
- **Guardrail metric**: metric that must not get worse in an experiment. (Ch 2)
- **Hallucination**: fluent output not supported by input or facts. (Ch 24)
- **HNSW**: graph-based ANN index with layered navigable small-world graphs. (Ch 18)
- **Hybrid search**: combining lexical (BM25) and dense retrieval, often with reciprocal rank fusion. (Ch 18)

## I–M

- **In-context learning**: model adapts to a task from examples in its prompt without weight updates. (Ch 15)
- **Interleaving**: comparing two rankers by mixing their results in one list. (Ch 26, 29)
- **Item2vec**: word2vec applied to sessions or baskets to embed items. (Ch 8, 25)
- **Kappa (Cohen's)**: inter-annotator agreement corrected for chance. (Ch 30)
- **KL divergence**: how one distribution differs from another; used as a penalty in RLHF and in distillation. (Ch 1, 13)
- **KTO**: preference alignment from unpaired thumbs-up/down labels. (Ch 13)
- **KV cache**: stored keys and values of past tokens to avoid recomputation during generation. (Ch 14)
- **LambdaMART**: GBDT-based learning-to-rank that optimises NDCG-weighted pairwise gradients. (Ch 26)
- **LLM-as-judge**: using an LLM to score or compare outputs, checked against human labels. (Ch 22)
- **LoRA / QLoRA**: training low-rank update matrices instead of full weights / doing so on a 4-bit quantised base. (Ch 16)
- **Learning to rank (pointwise / pairwise / listwise)**: losses on single items / pairs / whole lists. (Ch 26)
- **Logit**: unnormalised score before softmax or sigmoid. (Ch 6)
- **MAP / MRR**: mean average precision / mean reciprocal rank of the first relevant result. (Ch 5, 18)
- **Masked language modelling**: predicting hidden tokens from both sides. (Ch 11)
- **MCP (Model Context Protocol)**: open protocol connecting LLM apps to tools and data sources. (Ch 21)
- **MDE**: minimum detectable effect for a given sample size and power. (Ch 2)
- **Mixed precision**: computing in bf16/fp16 while keeping fp32 master weights. (Ch 7)
- **MoE (mixture of experts)**: router sends each token to a few expert networks; more parameters, same compute. (Ch 11)

## N–R

- **Negative sampling**: training with a few random negatives instead of a full softmax. (Ch 8, 25)
- **Novelty effect**: temporary change in behaviour because something is new. (Ch 2)
- **Nucleus (top-p) sampling**: sample from the smallest token set with cumulative probability ≥ p. (Ch 14)
- **Overfitting**: fitting noise in training data so test performance suffers. (Ch 3)
- **PagedAttention**: KV cache stored in fixed-size blocks to reduce memory waste (vLLM). (Ch 14)
- **PEFT**: parameter-efficient fine-tuning (LoRA, adapters, prefix and prompt tuning). (Ch 16)
- **Perplexity**: exp of average negative log-likelihood per token. (Ch 22)
- **Point-in-time join**: joining each label to feature values as they were at prediction time. (Ch 30)
- **Positional encoding**: injecting token order (sinusoidal, learned, RoPE, ALiBi). (Ch 10)
- **Precision / recall**: share of predicted positives that are right / share of actual positives found. (Ch 5)
- **Prefill / decode**: processing the prompt in parallel / generating one token per step. (Ch 14)
- **Prompt injection**: instructions hidden in content the model reads, which it then follows. (Ch 24)
- **PSI**: population stability index, a drift score between two distributions. (Ch 29)
- **p-value**: probability of data at least as extreme as observed if the null hypothesis were true. (Ch 2)
- **Quantisation**: storing weights or activations in fewer bits. (Ch 14)
- **RAG**: retrieval-augmented generation, grounding the model in retrieved documents. (Ch 19)
- **ReAct**: agent pattern interleaving reasoning and actions. (Ch 21)
- **Reciprocal rank fusion (RRF)**: combine rankings by summing 1/(k + rank). (Ch 18)
- **Regularisation**: techniques to reduce overfitting (L1, L2, dropout, early stopping). (Ch 3)
- **Reranker**: a slower, more accurate model re-ordering the top candidates. (Ch 18, 26)
- **Residual connection**: adding a layer's input to its output, easing gradient flow. (Ch 6, 10)
- **Reward hacking**: optimising a proxy reward in ways that do not reflect true quality. (Ch 13)
- **RLHF**: reinforcement learning from human feedback (reward model + PPO). (Ch 13)
- **RoPE**: rotary position embeddings, rotating query and key vectors by position. (Ch 10)

## S–Z

- **Scaled dot-product attention**: softmax(QKᵀ/√d)V. (Ch 10)
- **Self-consistency**: sample several reasoning paths and take a majority vote. (Ch 15)
- **Sentence transformer**: encoder fine-tuned so pooled embeddings reflect sentence similarity. (Ch 11, 17)
- **SFT**: supervised fine-tuning on prompt–response pairs. (Ch 13)
- **Shadow deployment**: new model receives copied traffic; outputs logged, not used. (Ch 29)
- **SHAP**: feature attributions based on Shapley values. (Ch 4)
- **Softmax / sigmoid**: turn logits into a distribution over classes / a probability for one class. (Ch 1, 6)
- **Speculative decoding**: a draft model proposes tokens that the large model verifies in one pass. (Ch 14)
- **SRM (sample ratio mismatch)**: observed traffic split differs from the design, signalling a bug. (Ch 2)
- **Structured output**: model output constrained to a JSON schema. (Ch 14, 15)
- **Teacher forcing**: feeding true previous tokens during training. (Ch 8)
- **Temperature**: divides logits before softmax; lower is more deterministic. (Ch 14)
- **Test-time compute**: spending more inference tokens (reasoning, sampling) to improve accuracy. (Ch 11, 13)
- **Tokeniser**: maps text to integer ids from a fixed vocabulary. (Ch 9)
- **Tool calling (function calling)**: model outputs a structured call that the application executes. (Ch 21)
- **Training–serving skew**: features computed differently in training and production. (Ch 29)
- **Two-tower model**: separate user and item encoders producing embeddings for fast retrieval. (Ch 25)
- **Uplift modelling**: predicting the effect of a treatment on each individual. (Ch 2, 27)
- **Vanishing / exploding gradients**: gradients shrinking or growing exponentially through depth or time. (Ch 6, 8)
- **Vector database**: storage and ANN search over embeddings with metadata filters. (Ch 18)
- **VLM**: vision-language model, an LLM that takes images as input. (Ch 11)
- **Weight decay**: penalty pulling weights towards zero. (Ch 6)
- **Word2vec**: shallow model learning word embeddings from context prediction. (Ch 8)
- **Zero-shot**: performing a task with instructions only, no examples. (Ch 15)
